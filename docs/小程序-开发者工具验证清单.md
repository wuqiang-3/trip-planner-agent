# 微信小程序 v1 · 开发者工具验证清单(图文版)

> 目的:在合并代码前,由你在本机用「微信开发者工具」把小程序真实跑一遍。
> 说明:本文用「界面示意图」代替截图(截图需在你本机产生)。照着每步做,核对「预期效果」即可。
> 代码位置:`~/Desktop/trip-planner-agent/miniprogram/`,分支 `feat/wechat-miniprogram`。

---

## 准备:需要你手上有的东西

- [ ] 已安装 **微信开发者工具**(稳定版,macOS):https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- [ ] 后端能跑(`backend/.env` 里已填 **LLM key** 和 **高德 key**)
- [ ] 一个微信小程序 **AppID**;没有也行,导入时选「测试号」

---

## 第 0 步:启动后端

终端执行(在仓库根目录):

```bash
cd ~/Desktop/trip-planner-agent/backend
pip install -r requirements.txt          # 第一次需要
uvicorn app.api.main:app --host 0.0.0.0 --port 8000
```

**预期效果**:终端出现 `Uvicorn running on http://0.0.0.0:8000`。
浏览器打开 `http://localhost:8000/docs` 能看到接口文档页。

- [ ] 后端已启动,`/docs` 能打开

> ⚠️ 如果这一步报错(缺 key、依赖装不上),先解决后端再继续。小程序所有"真实生成"都依赖它。

工具右上角 →「详情」→「本地设置」:

```
┌──────────────────────────────┐
```

- [ ] 「**不校验合法域名…**」已勾选

> 不勾这个,小程序不让你请求 `http://localhost:8000`,生成会直接失败。

## 第 4 步:验真实生成(连后端走完整流程)

把编译模式切回「普通编译」(启动页 `pages/index/index`)。

### 4.1 填表单

```
┌──────────────────────────────┐
│ 🧳 智能旅行助手               │
│ 目的地城市  [ 杭州 ]          │
│ 出发日期    [ 选今天 ]        │
│ 返程日期    [ 选+2天 ]        │
│ 交通方式    [ 公共交通 ▼ ]    │
│ 住宿偏好    [ 经济型酒店 ▼ ]  │
│ 旅行偏好    [美食](点亮)      │
│ 额外要求    [ 选填 ]          │
│        [ 生成行程 ]           │
│       查看历史行程 ›          │
└──────────────────────────────┘
```

- [ ] 偏好标签「美食」点一下变蓝(再点取消),说明多选生效

### 4.2 先验校验(故意填错)

- [ ] **不填城市**点「生成行程」→ 底部弹提示「请填写目的地城市」
- [ ] 返程日期选得**比出发早** → 提示「返程日期不能早于出发日期」

### 4.3 正常生成

填对后点「生成行程」:

**预期效果**:
```
┌──────────────────────────────┐
│         (整屏白色遮罩)        │
│            ◌ 转圈             │
│       正在搜索景点…           │ ← 文案每1.5秒切换
│  行程生成约需30秒至2分钟…     │
└──────────────────────────────┘
```

- [ ] 出现全屏转圈 + 文案轮播(理解需求→搜索景点→查询天气→规划路线→编排行程)
- [ ] **30秒~2分钟内**自动跳到结果页,渲染**真实**行程(你填的城市)
- [ ] 内容合理:有景点、有天气、有预算、有总体建议

> 后端这一步会真的调大模型 + 高德,慢是正常的。只要最终出结果即可。

## 第 5 步:验历史 + 分享闭环

- [ ] 结果页左上返回 → 回到首页 → 点「查看历史行程 ›」
- [ ] 历史页能看到刚生成那条:「杭州 · 3日游 + 时间」
- [ ] 点这条 → 再次进入结果页,内容和刚才一致(走的是本地缓存,秒开)
- [ ] 历史条目右侧「删除」→ 弹确认 → 确认后该条消失
- [ ] 全部删光 → 显示空状态「还没有历史行程 / 去生成一个 ›」

## 出问题时的快速排查表

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| 导入报 app.json 找不到 | 目录选成了仓库根 | 重选到 `miniprogram/` 子目录 |
| 生成一直失败/报域名 | 没勾「不校验合法域名」 | 第 2 步勾上 |
| 生成报网络错误 | 后端没启动 / 端口不对 | 查第 0 步,`/docs` 能否打开 |
| 真机预览连不上 | 真机访问不了 localhost | 改 `config/env.js` 的 `BASE_URL` 为电脑局域网IP,后端 `--host 0.0.0.0`,手机电脑同WiFi |
| 结果页空白 | mock 数据/字段问题 | 截图+控制台发我 |
| 生成很慢(1~2分钟) | 正常(大模型+高德多次调用) | 耐心等,有转圈即正常 |
